# CardUpgrade 蓝湖切图

来源：蓝湖「占城项目 / 卡牌(1) / 版本2」（image_id `df735b11-3690-4883-93ac-0dda3d6f4447`），用户提供的 `卡牌(1)_slices/mipmap-xhdpi`。

PNG 按原名原尺寸导入，不重新裁切；meta 由 Cocos Creator 3.8.8 生成，九宫格边距经 Cocos MCP 设置。复用父目录 `carddetail/auto-atlas.pac`，不增加子图集。

这些切图仅接入 `CardUpgrade.prefab`。技能、品质、角色与材料继续消费当前运行时数据及原有资源管线；`CardSkill` 的皮肤和升级规则保持原样。

布局按蓝湖 721×1610 标注校准，字体使用系统 `Microsoft YaHei`（微软雅黑）：标题 34 加粗、战力 33 加粗、属性名称 22、属性值 24、技能说明 24 常规。上方展示固定尺寸并顶对齐；底部区域使用 Widget 百分比边距（设计高度下为 350），仅底板和区域间距随屏幕高度变化，文字、图标、按钮保持固有尺寸。技能列表填充剩余空间并滚动，短屏不缩放整个展示区。角色脚底使用固定基线，待机可见高度 390。

技能链底框使用原始 `jineng_bg`（103×116）、`frame_s_01/02` 蓝紫标签及 `icon_lock`。`jineng_01`、`zhezhap_02` 由同一蓝湖快照的原图导出（节点 1534、1538，原图 182×204、206×232，展示尺寸 91×102、103×116）。图层在 prefab 中预绑，运行时仅切换锁、标签和角标；锁定说明使用真实解锁等级，长技能名在标签宽度内缩字。
