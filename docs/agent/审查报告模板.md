# 审查报告模板

> 用法：复制本文件到 `outputs/audit-<日期>/审查报告.md` 后逐项填写。标准与流程见[代码审查规范](代码审查规范.md)。
>
> 本模板刻意不写「以 `|` 开头且含完整用例路径」的表格行——`tools/verify/verify.mjs` 会把这类行误收进路由表（规范 §7）。具体命令一律写在列表项里。

## 三、三条判据

| 判据 | 结果 | 说明 |
| --- | --- | --- |
| 新增失败用例 = 0 | PASS / FAIL | 按用例名集合双向差集，非总数 |
| 新增 tsc 错误 = 0 | PASS / FAIL | 按文件 + 错误码指纹差集 |
| 无覆盖改动文件 = 0 | PASS / FAIL | 非 0 时逐个写明人工验证方式 |
| 退出码非 2 | PASS / FAIL | 2 表示工具自身出错，本次结论作废 |

## 附：提交说明模板（纯中文日志）

版本库约定要求提交日志纯中文，禁止英文或中英混排；命令与路径不写进日志正文，放报告里。

```text
本次变更：<中文一句话说明改了什么、为什么>
验证：路由门禁与差异校验通过，相对基线无新增失败用例、无新增编译错误、无未覆盖改动文件。
未覆盖：<如实写明未启动引擎预览、未跑全量等>
```

SVN 提交仅用 TortoiseProc 图形通道，提交按钮由人手动点击；未核实结果前不写"已提交"。
