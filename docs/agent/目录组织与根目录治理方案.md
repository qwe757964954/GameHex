## 4. 为什么测试不按域搬目录

`tools/verify/verify.mjs` 的 `listTestFiles()` 只读 `tests` 顶层：

```js
fs.readdirSync(path.join(ROOT, 'tests')).filter((f) => f.endsWith('.test.ts'))
```

把 `.test.ts` 放进 `tests/xxx/` 会被默认发现逻辑漏掉；同时 `AGENTS.md`、路由表、`package.json` 里散着大量 `tests/xxx.test.ts` 硬编码路径。因此保持平铺，用**文件名前缀**分域，`tests/README.md` 的索引负责可发现性。夹具进 `fixtures/`、辅助进 `helpers/`，不参与用例扫描。

## 7. 防回流机制

| 机制 | 位置 | 作用 |
| --- | --- | --- |
| 根目录白名单守卫 | `tools/check-root-hygiene.mjs` + `npm run verify:hygiene` | 根目录出现非白名单文件即 exit 1，并给出应去目录 |
| 守卫流水线 | `npm run verify:guards` 末尾 | 提交前跑守卫时自动检查根目录 |
| Agent 规则 | `AGENTS.md`「目录与文件归属」 | 明确文档/测试/日志/临时产物的归属，禁止根目录新增 `.md`/`.log` |
| 文档规则 | `docs/README.md` | 目录职责、生命周期、路由真源改名前置条件 |
| 日志规则 | `logs/README.md` | 命名、`*>` 写法、14/90 天保留期 |
| 测试规则 | `tests/README.md`「目录约束」 | 禁止 `.test.ts` 子目录化，改名后重算索引 |
| Git 忽略 | `.gitignore` 的 `*.log` + `/logs/archive/` | 日志文件与归档不入库 |
