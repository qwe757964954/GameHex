## 8. 注意事项

- Widget：全对齐 `_alignFlags=45`；常用位 `top=1`、`bottom=4`、`left=8`、`right=32`、`verticalCenter=2`、`horizontalCenter=16`。迁移时优先固定“设计稿上不动的那条边”，让另一条边随屏幕伸缩。
- Layout：`_layoutType` 1=HORIZONTAL、2=VERTICAL、3=GRID；`_resizeMode` 1=CONTAINER、0=NONE；GRID 用 `_constraint=2` + `_constraintNum`；`_verticalDirection=1` 为顶→底。
- 双态节点：prefab 只能存一套位置。像 ChestSlot 的 `Clock`（等待态动态居中、倒计时态回 prefab 基准）必须在 `onLoad` 缓存 prefab 基准，切态时复位；只删常量不复位会出现图标叠在胶囊上。
- 测试：生产常量删除后，测试夹具可保留旧数值用于几何断言，但不得再 import 生产常量，否则会制造第二真源。
- prefab 手工 JSON 写入后必须由编辑器刷新生成 library；`cc.PrefabInfo.fileId` 为 22 字符，普通节点需有 `cc.PrefabInfo`，嵌套 PrefabInstance 的 `fileId` 允许随源 prefab 重复。
