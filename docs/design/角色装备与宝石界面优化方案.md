## 1. 结论

上一版弹窗的问题不是配色，而是**没有用游戏里已有的弹窗资源**：细边纸卡、亮青蓝按钮、橙色药丸页签都是 CSS 拟出来的，和现有「巡逻宝箱」不是一套语言。

现有弹窗的真实语言（`TerritoryMonsterBoxPanel.prefab`）是：

- **面板**：灰黑外圈 + 米色内芯 + 四角螺丝，9 宫拉伸；
- **标题**：带绿叶、螺丝的厚木牌，不是红绸带；
- **分区头**：红色缎带 + 金边六角徽章，文字米白描边；
- **内衬板**：浅棕圆角板 + 一圈米白内线，不用 1px 深棕描边；
- **物品卡**：奶油色小圆角卡，品质色方块套在卡里；
- **按钮**：黑边、亮面、大圆角的蓝 / 橙双色按钮，蓝色为次、橙色为主。

本轮只重做两个弹窗，装备栏维持上一轮的「去底盘 + 96×24 宝石条」不动。

三条原则：

1. **切图 1:1 复用**：面板、木牌、关闭、缎带、内衬板、物品卡、蓝/橙按钮全部来自现有 prefab 引用，不新增美术。
2. **两个弹窗共用一套壳**：宝石详情 660×760，装备详情 660×840，宽度一致，按内容裁高。
3. **数值不再用彩色字**：浅棕板上绿字 / 橙字对比不足；统一墨字 + 7px 语义色点，颜色只做标记，不做正文。

## 9. 风险与待确认

1. **跨 bundle 引用**：`bg.png` 等来自 `assets/resources/image/...`，Role prefab 在 `main-pages` bundle；必须确认 `resources` 已随角色页加载。若没有，复制所需小图到 role 目录，成本是重复资源，不是新美术。页签与等级底来自 `main-pages` 自身，不受这条影响。
2. **`item_frame` 无九宫**：126×151 缩到 116×116 / 92×96，圆角和细边会被等比压扁；小卡可接受，大板必须用 `frame_guard` / `frame_01`。
3. **弹窗尺寸变化**：宝石 480×560 → 660×760，装备 540×880 → 660×840。宝石弹窗明显变大，是为了放下 5 张原生孔位卡和 231+321 原生按钮；若必须保持 480 宽，只能缩按钮或改成 2×3 孔位，会离参考更远。
4. **`contentNodes`**：`titleBar`、`btnClose` 必须加入，否则点木牌/关闭会被 `PopupBase` 判空白关窗。
5. **页签选中态**：当前代码只切 `equipViewRoot/gemViewRoot` 显隐，从不改页签外观；P0 必须补 `tabEquipActive/tabGemActive` 节点与文字色切换。
6. **左右切换箭头**：现 prefab 是 58×72 挂在面板外；660 宽下面板外只剩 30px，会出屏。建议改成 44×44 挂在面板内缘，或把面板收到 620；本轮效果稿暂未画箭头，需拍板。
7. **清空确认**：现无二次确认，直接循环卸下；是否加确认、文案是否提"不可恢复"，需策划确认。
8. **锁定语义**：代码只有 `CmdGemLockReqMsg`，界面未解释锁定后限制（分解/出售/合成）；本轮只做视觉，文案待策划给口径。
9. **属性溢出**：`effects` + `gemEffects` 理论最多 5+2 行，加基础 3 行会超过 8 行；P1 先按 8 行设计，溢出场景必须用滚动或折叠，不能静默裁切。
10. **页签 / 等级底 / 关闭尺寸**：`btn_04` 原图 249×65 拉到 280×60，`yx_img_heidi` 原图 668×60 压到 560×56，`dj_bg` 100×122 缩到 62×85，`btn_close` 92×91 缩到 84×83；都会等比缩放，边缘会有轻微软化。若美术不接受，改为原尺寸或补 9 宫，不另绘新图。
11. **参考图是两页还是三页**：`1ed` 是“宝石 / 装备 / 道具”三段，但本弹窗只有装备属性 / 宝石镶嵌两页；第四版按两页落地，保持轨道 + 橙选中语言，不新增“道具”页。若后续要把弹窗扩成三页，需要产品先定第三页语义。
12. **史诗品质底**：头部直接铺 `rl_bag_quality_04` 后，紫色会占满 116×116；这是有意强化“史诗鞋已装备”的识别，若觉得过重，可退回“奶油卡 + 96 紫框”的第三版。该底色只用于装备详情，不扩散到宝石详情。
