## 实现范围

- `ZCNeutralFeatureSystem`：含中心的领地格距、排除空洞、各方永久解锁、独立集火冷却、首次集火永久唤醒、原地锁敌、持续反击资格、连续脱战延迟及小数回血。
- `ZCGameModel` / `ZCUnitTargeting`：战斗中切换集火、圈外遇敌、取消后反击当前攻击者、尾刀一次性原点满血援军、清除野怪状态。援军隔离领取方基础培养和阵容加成，普通攻击及技能运行时使用野怪基础配置；首个攻击冷却也恢复基础值。
- `ZCMatchRuntimeCompiler` / 攻击、旧技能系统：编译无领取方修正的技能运行时。`ZCSnapshotCodec` 校验并保存解锁、集火、反击、回血和援军属性。
- `ZCHexView` / `ZCGameRenderWorld` / `ZCBattleRuntimeController`：按钮经意图事件进入模型；显示独立状态与小数冷却；血条、地表覆盖和击杀后地表保留。
- `ZCGameLegendBannerView` / 两个相关 prefab：集火按钮挂真实 `cc.Button`；击杀横幅显示阵营色、玩家名、野怪名和援军结果，隐藏普通传说卡标题。
- 地图编辑器 `app.js` / `server.mjs`：载入地表参数并预览同一领地规则，空洞不会造成绕路或补格。
