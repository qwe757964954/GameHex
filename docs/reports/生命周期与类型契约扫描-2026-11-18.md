## 2. 方法与边界

1. 先用 TypeScript AST 枚举全部 `IndexedAccessTypeNode`，按嵌套深度、上下文（参数 / 返回 / 字段 / 类型别名 / 断言）分类；再用类型检查器把每个节点解析成具体类型，判断是否已有可复用的具名声明。
2. 对生命周期候选逐个追踪：字段何时赋值、所有调用者、何时清空、缓存重开、销毁与异步返回路径；组件字段额外核对对应 prefab 绑定（本轮只对 `MainTerritoryMap` 做了逐字段核对，见 §6）。
3. 搜索结果只作候选。每项在 §3/§4 给出原始声明、调用顺序或测试证据；不能证明的进 §5 或 §6。
4. 不使用批量正则替换；不新增默认值、`as any`、访问点非空断言来替代原防护；不修改生成文件与配表。
