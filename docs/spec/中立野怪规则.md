# 中立野怪规则（2026-11-17）

依据桌面交接包《中立野怪开发需求_优化版.html》，并同步 2026-11-20 的集火唤醒与领地占领规则。其他中立资源沿用原规则。

## 配置与基础强度

- `neutralResourceGroup.resourceType=11`；组合 `14009` 固定条目 `1400901`，权重 `10000`，卡牌 `68007`。
- `param={resId:"68007",wakeRange:2,reviveRate:1}`。`wakeRange` 为正整数；`reviveRate` 为有限正数，可小于或大于 1。删除独立 `attackRange`；攻击距离和其他基础属性来自 `pvpCard` 编译出的单位定义。
- `icon` 表示领地地表名，`0` 表示不铺；模型、预览和播报图使用卡牌资源。领地使用含中心的六边形最短格距半径，再排除空洞，不绕路、不补足格数。击杀后保留地表。
- `S-数据配置.xlsx` 导出的 `gameConfig` 提供：`neutralMonsterFocusSwitchCdSeconds=3`、`neutralMonsterRegenDelaySeconds=3`、`neutralMonsterRegenRate=0`。前两项允许非负小数秒；回血速率为非负整数，单位是每秒最大生命的万分比。当前正式运行数据位于 `refSmallAll.json.gameConfig`。

## 解锁与集火

各方在领地内拥有存活建筑后分别永久解锁，建筑被毁不撤销。任一方首次开启集火时野怪醒来，此后不再沉睡。集火开关只控制己方单位；每次开启和取消均进入配置冷却。按钮显示未解锁、集火野怪、取消集火和冷却剩余秒数。按钮位于血条上方，始终显示在经过的士兵前面。

开启时，未交战及新生单位优先前往野怪；已经与敌军交战的单位，在自身可攻击野怪或已进入领地时切换，并在此条件内保持集火。两条件均不满足时继续当前战斗，途中遇敌正常交战，结束后继续前往野怪。

关闭后野怪仍可被正常索敌。正在攻击野怪的单位受到敌军攻击时可反击；取消瞬间也能反击仍在攻击自己的有效敌军，不追溯历史仇恨、不强制撤退。

## 野怪攻击与回血

野怪原地不移动，只攻击单位，不攻击建筑。沉睡时不能被索敌或伤害，包括范围伤害。唤醒后保留有效当前目标，失效后选择最近可攻击单位。沉睡时模型变暗，唤醒后恢复原色。出手时面向目标，目标在正上方、正下方或脚点重合时保持原朝向。出手时播放一次 `attack`，按怪物卡的命中时点结算一次伤害。起手目标失效时该次攻击落空。动作结束后回到待机，下一次出手同时受攻击间隔约束。中立模型的缩放采用怪物卡的 `prefabSize`，模型在出生格水平居中，脚下与地面贴合。

实际攻击过野怪的存活且可攻击单位获得持续反击资格，即使离开射程、取消集火或改变目标也不撤销；不会因此抢走野怪现有有效目标。死亡或不可攻击后清除资格。

仅已唤醒且未归属的野怪回血：没有有效攻击目标（包括远处仍有反击资格者），也没有单位正在攻击自己，连续满足配置延迟后开始。回血量为实际最大生命 × 速率 ÷ 10000 × 经过秒数，小数血量累计，最大不超过满血。重新交战立即停止并重算等待时间。援军不使用此回血规则。

## 领地占领

单一阵营的小兵踩过野怪领地内的可占领格（含野怪出生格）后，格子立即归该阵营，无需驻留或补给。多个阵营同一逻辑拍经过同一格时保持原归属。有存活建筑、未破城墙或受其他中立资源规则保护的格子按原规则处理。踩格只改变土地归属，存活野怪仍独立战斗，地表保留并叠加阵营底色。

## 击杀与援军

尾刀方获得一次援军：在原点满血复活为正常单位，生命上限和攻击力按野怪基础值乘 `reviveRate`，其他基础属性保留。隔离领取方的武将培养、阵容加成及技能培养，倍率不再次叠加。之后阵亡按普通单位清理，不再复活。

击杀时清除集火、野怪锁敌、反击资格和回血计时。双方视角均显示阵营色、玩家名、野怪名与获得援军结果。当前复用普通出生表现、阵营标识和现有横幅底板；正式地表、播报/复活美术、音效和停留时长待提供。回血最终延迟和速率待调试。
