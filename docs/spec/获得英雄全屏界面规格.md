# 获得英雄全屏界面（HeroObtain）规格

> 状态：实现说明（最后核对 2026-11-20）。
> 对应代码：`assets/script/app/card/view/HeroObtainPage.ts`、`assets/script/app/card/model/HeroObtainLayout.ts`
> 预制体：`assets/resources/ui/heroObtain/HeroObtain.prefab`
> 验证：`npx tsx --test tests/hero-obtain-layout.test.ts tests/hero-obtain-assets.test.ts`

---

## 1. 结构与生命周期

- **Page 职责**：继承 `PopupBase`，全屏展示新获得英雄或英雄碎片升星展示。
- **纯函数计算**：动画缓动、进度百分比、时间轴采样统一收敛在 `model/HeroObtainLayout.ts`（零引擎依赖，可直接单测）。
- **坐标口径**：动画节点不挂 `cc.Widget`，位移仅相对 prefab 的设计最终坐标做临时偏移；根级 `Stage` 居中适配短屏与长屏。

---

## 2. 四段时序动画（`HERO_OBTAIN_TIMELINE`）

1. **入场（Entrance）**：底图淡入 → 放射光放大淡入 → 标题从上方落下回弹（`EaseOutBack`）。
2. **卡片展示（Hero Reveal）**：英雄从下方浮起 + 淡入（骨骼自带投影）→ 名牌弹入 → 职业徽标/名称淡入。
3. **光效与进度（Progress）**：进度条底板淡入 → 填充从左长满 + 数字同步滚动（`heroObtainCountTextOf`）。
4. **收尾（Close Hint）**：「点击屏幕继续」淡入；放射光进入常驻顺时针自转（`heroObtainRaysSpinAngleOf`）。
