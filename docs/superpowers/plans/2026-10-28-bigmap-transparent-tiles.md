# 大地图透明格实施计划

**Goal:** 透出已有无缝背景，格子以半透明色和淡格线表达地形，势力范围继续使用现有色板。

**Architecture:** 在 BigMapWorldView 的无缝背景模式停用沙地图 Sprite，复用 TerrainLayer Graphics 绘制当前视口的格子。装饰与建筑仍沿用原有模板、视口裁剪及点击几何；已有势力着色与描边不变。

**约定:** 空地完全透明，森林 / 岩地 / 水面只加轻色；保留淡格线。资源未就绪时沿用现有展示路径。相机平移到地图外必须清空原来的格子，模式切换必须清理旧沙地图槽位。

- [x] 真实视图方法的 VM 回归先失败：透明显示、无沙地图依赖、裁剪与模式切换。
- [x] 接入透明格绘制与独立装饰池，不创建另一套世界状态或拾取规则。
- [x] 跑大地图相关测试，并在真实预览中验证无缝背景、势力区分、缩放 / 平移 / 点击。

**验证记录:** 定向 34 项全部通过。真实引擎各缩放背景覆盖、不透明格数 0、势力颜色 5 种、实际鼠标选中 1122、SpriteFrame 无失效、运行时错误 0。扩展配色测试另外有 4 项已有失败，分别来自 world_01 的范围覆盖与邻接数据；这些用例只读模型和地图，未消费本次修改的视图。未修改这些地图数据。
