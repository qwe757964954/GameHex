# 章节关卡气泡实施计划

**Goal:** 章节地图已解锁的关卡建筑使用与大地图相同的圆角编号气泡。

**Architecture:** 共用无运行时引擎依赖的气泡尺寸、定位和绘制函数；章节站点只消费关卡号，沿用现有站点点击事件与共享角标层。气泡随站点隐藏、淡入和销毁。

**Tech Stack:** Cocos Creator 3.8、TypeScript、tsx/node:test、真实预览引擎探针。

**约定:** 编号取关卡配置 stage；未解锁继续显示银币条件。建筑上方留 3px 空隙，气泡 88×30、15 号白字、8px 圆角，样式来自现有大地图。无有效建筑或关卡号时隐藏。资源与非关卡站点不显示编号。

- [x] 添加站点气泡显示、隐藏、摆位、点击与回收测试，先确认失败。
- [x] 提取大地图公共绘制及排版常量，章节站点接入编号与共享角标层。
- [x] 运行关卡表现与大地图最小回归集；刷新脚本，通过真实引擎检查气泡节点、截图与资源生命周期。

**Review focus:** 成本格复用后无残留气泡；关卡数字来自配置；建筑 trim/buildSize 后不遮住图；隐藏与生成透明度覆盖背景和文字；点击气泡仍走原站点意图；退出页面不留游离节点。

**验证记录:** 真实预览中验证 1/5/12 三个气泡的尺寸、位置、隐藏与渐入，无无效图帧或运行时异常。复查发现透明命中层会抢走相邻行气泡点击，已把共享角标层排在命中层之后；真实鼠标点击从错误选中上方站点 100 变为正确选中下方站点 0。定向 42 项回归全部通过。扩展集的现有失败涉及旧 resources 大地图 Prefab 路径与装饰建筑高度，不改动这些无关资产。
