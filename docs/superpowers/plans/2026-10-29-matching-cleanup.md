# Matching 模块整理

**Goal:** 将匹配页已有的注释、命名及生命周期整理扩展至 matching 全模块。

**Architecture:** 保留页面、信息条、配置与资料各自职责，复用 AssetService、ConfigService 和 ResourceScope；不增加全局状态或修改协议、Prefab 绑定。

**Constraints:** 保留工作区既有修改；公开显示数据契约与 Inspector 属性兼容；不自动提交。

- [x] 图标与配置：先用行为测试覆盖作用域释放、并发加载、失败重试和配置来源隔离，再移除未使用的直接加载入口及静态缓存。
- [x] 信息条与资料：测试复用后旧图标清理和玩家数据副本隔离，精简注释与变量；保持异步失效、布局和资源路径不变量。
- [x] 检查 MatchingPage、MatchPool、MatchStatItem、MatchTypes；删除多余状态，修正过时说明，保持现有流程行为。
- [x] 执行匹配、图标、开战协议、预加载、头像与路径相关单测，检查差异及局部类型诊断。

**Review focus:** 缓存不可跨资源作用域；相同图标并发加载不重复；失败不固化为空缓存；视图复用不能显示上一条数据；异步返回不得访问已销毁组件；公开字段和 Prefab 绑定保持兼容。

**验证结果：** 81 项相关回归测试及 1 项匹配资源路径测试通过；差异空白检查通过。完整资源路径测试另有 5 项失败，涉及卡牌、指南、角色及民兵缺图。全仓 TypeScript 检查仍有引擎等既有诊断，matching 模块及新增资源测试无诊断。未做引擎内画面验收。

**只读复核：** 未发现本次改动引入的可操作问题，独立复跑匹配资源及生命周期测试 16/16 通过。保留原有头像/神器加载失败时的占位行为与动画架构；同页提示翻页中重启的旧限制不在本次整理中改造，正式流程每次创建新页面。
