# 大地图玩家协议接入实施计划

目标：补齐现有玩家协议从请求、缓存、广播到显示和迁城输入的闭环。基于 Creator 3.8.8，沿用现有 MVC、头像入口、PopupBase 和网络归属，不改协议生成文件。

- [x] 玩家快照：可见据点刷新角色列表；广播更新已知玩家，未查询据点补查；跨城移动清理旧记录，失效查询不回滚。
- [x] 展示：复用标记模板绘制真实玩家；联机不画布局 NPC；通过城池按钮逐位查看全部角色（头像、名称、区服、ID、建筑等级、HP、pos）。
- [x] 迁城：意图 → Controller → Model → Repository；目标格须属于选定城池，确认后发原始 pos；写入串行、禁止重发，失败保留快照，退出取消回调；结果后重拉迁出/迁入事实。
- [x] 验证：行为测试覆盖查询/广播/取消/跨城/重复操作；编辑器核实按钮绑定和模板；对比改前测试失败用例和 tsc 错误指纹。保留用户已有修改，不提交版本库。
