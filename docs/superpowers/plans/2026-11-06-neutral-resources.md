# 趣味中立资源实施计划

**Goal:** 按钉钉《趣味中立资源》的简明修正版扩展现有 PVP 中立资源。

**Architecture:** 复用资源组合表和地图 groupId；新增参数由编译边界校验。对局系统维护快照状态，视图只显示状态、类型和效果。兵营首波、周期波、号角波共用产兵入口，传送只在该入口改变出生格。

**Tech Stack:** Cocos Creator 3.8.8、TypeScript、tsx node:test、既有 Excel 导表链。

**Spec:** 用户确认以简明修正版为准；待定项沿用现有规则。门不可攻击、双方共用冷却并可易手；野怪、衍生地块、号角先到先得。

## 边界

- 固定门效果默认不变，随机模式由表配置且不连续重复。
- 新单位继承来源当前属性和大小，满血；人口上限继续生效。
- 衍生线一次远程建造权仍付费，不占用资源格、虚空、废墟或已有建筑。
- 传送仅双人局、至少两座本方门；同距保持出口，原出兵进度不变。
- 野怪平均等级统计、奖励归属和复活未定，不引入新结算规则；复用配置卡属性和现有击杀奖励口径。
- 保留工作区已有战斗、大地图和资源改动。
