# 对局配置归属与冗余清理

目标：解决预编译并发及 reset 后旧任务安装，收拢共享配置状态，让正式对局直接消费地图数据，减少重复配置快照。

## 实施边界

- 共享配置是应用配置服务，初始化由 ProcedureBootstrap 注入，会话 clear/reset 清除全部目录及在途任务版本；不承载每局状态。
- ZCRuntimeConfigStore 保存单个已编译配置快照和预编译任务。并发复用一个 Promise；重置后的旧任务返回 false，不发布数据；失败释放任务，允许重试。
- 现有只读目录 API 保留业务意义，内部统一读取仓库；删除分散变量与无独立契约的 setter。编辑器阵容预览保留部分目录加载语义。
- 地图解析为纯函数，复用 ZCMatchMap；正式 Loader 保存返回的数据。旧离线工具的 configureZCMap 仅应用解析结果，不复制校验。
- 已由真实入口创建并冻结的配置重复捕获时复用；普通外部对象继续复制隔离，不用单纯 Object.isFrozen 判断来源。
- 冗余清理限定在上述调用链；不改配表、资源文件、业务参数或无关模块。
