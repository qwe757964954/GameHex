# zcds 弹道碰撞

`projectile` 技能在出手帧生成 `ZCProjectileState`，从下一逻辑步开始飞行。子弹直线飞向出手时的瞄准位置，速度读取 `projectileSpeed`，缺省为 500 个逻辑坐标单位/秒；飞到终点仍未命中即消失。飞行时间直接由距离和速度计算。

每个 20 Hz 逻辑步先记录小兵位置，再更新小兵，最后推进弹道。小兵的移动轨迹和身体半径写入空间网格；子弹查询经过的网格，再进行相对运动的线段扫圆检测。高速子弹跨过小兵、移动小兵横穿轨迹、起点重叠和擦边接触都能检测。超长轨迹回退为候选扫描，避免遍历大量空格。

默认忽略友军、死亡单位和攻击者不能攻击的飞行单位。只命中轨迹上第一个敌人后消失，同位置按单位 ID 取小者。对墙或建筑发射时，前方敌兵可以拦截；目标墙或建筑使用逻辑圆形范围检测，命中时读取当前防御和阵营状态。未实现途中其他城墙的逐边阻挡。

技能表可新增可选的正数 `collisionRadius` 列，缺省为 3。子弹半径和单位 `bodyRadius` 都乘以本局 `combatDistanceScale`。配置缺省时，现有技能表可以直接使用。

子弹记录发射者 ID、阵营、卡牌 ID 和出手时的基础伤害，命中时根据实际目标计算克制。攻击者死亡或移除后子弹继续飞行，伤害和击杀奖励仍归发射方。

`snapshot.projectiles` 保存全部在途弹道；旧 version 4 存档缺失该字段时补空数组。存档恢复保留子弹位置、速度和生命周期，`combatEvents` 只保留瞬时表现用途，导出时依然清空。重开对局清空弹道及碰撞缓存。

单位视觉位置统一使用 `freeX/freeY`，取消仅存在于显示层的阵型偏移。飞行特效读取弹道上一步和当前坐标插值；命中时回收飞行节点并在接触位置播放短暂命中特效。命中特效不造成额外范围伤害。

本阶段适用于远程单位的 `projectile` 普攻，包括强化普攻。近战、范围技能、神器和现有防御塔伤害维持原规则；穿透、追踪、爆炸弹道和真实墙边阻挡可在此系统上扩展。
