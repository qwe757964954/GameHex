## 配置入口

PVP 开战回包提供 `CmdPvpMapInfo` 时，以本局快照为准：`id`、`version` 精确匹配地图 JSON（`version` 直接对应 JSON 的同名字段），地形与美术仍由该地图提供；`unitHomeIndexes` 非空时通过参战 `unitId` 指定 `homes` 下标，作为最终出生点，跳过自选主城；自选地图（`cityMode=select`）的空列表表示尚未分配出生点，保留既有选点流程，分区不重排，资源仍采用服务端快照。客户端按本机玩家视角同步转换主城和分区。`resourcePoints` 的坐标、组合和 `resourceId` 直接冻结进本局，空列表表示本局无资源，不再读取本地投放结果或重新抽签。缺图、版本不符、固定模式出生点缺失、非空出生点分配不完整或资源配置不匹配时终止本次准备。无快照的既有本地流程保持原有选图、选点和抽取行为。

强化门组合参数仅为 `{"gateIds":[101]}`：单个ID固定，多个不同效果ID随机，初始等概率抽取，每轮从其余ID选择，不连续重复。效果与数值来自同本 Excel 的“强化门”工作表，导出 `neutralEnhanceGate`：`effectType` 为1加法、2乘法、3放大、4缩小；`value` 为额外兵数或总倍数；`scale` 为实际体型倍率；`hpRate` 为最大生命倍率；`windowSeconds`、`cooldownSeconds` 为各效果自己的时间。缩小使用 `attackSpeedMultiplier`、`moveMultiplier`、`damageMultiplier`，不适用字段填0。放大倍率基于未受门影响的最大生命，重复经过不叠乘。

割草机（类型8）参数为 `{"damageRate":1,"speed":2}`，分别为全队总攻击力伤害比例、每秒前进格数。移除 `buildCostMode` 和整线特殊建造权。传送门（类型9）参数为 `{"range":6,"uses":3,"cooldownSeconds":10}`，范围按逻辑格距，次数按出兵批次；只有实际能出兵的批次才消耗次数。一个门即可生效；范围内优先最近存活敌人，无敌人则朝敌方主城方向选择最大范围内的有效出生格，无须另一座门。

保留现有地图14001～14009组合ID，并引用同一份强化门配置；桌面表原有17001、18001、19001、19002组合也可供地图编辑器使用。号角参数为 `{}`。野怪参数为卡牌字符串 `resId`、`wakeRange`、`attackRange`，继续沿用卡牌属性与击杀奖励。

## 状态与接入

- 普通中立资源和趣味中立资源均在相邻任一方格子已翻开（`developmentResolved = true`）后自动生效；仅有归属、尚未翻开的邻格不触发。强化门领取前不触发穿越效果；野怪也须先满足已翻开的邻格条件，不能由远处格子提前唤醒。无需点击资源格本身，不等待翻格表现动画结束。
- `ZCNeutralFeatureSystem` 为每局实例；当前强化门ID、冷却、判定窗口、格内单位、领取状态、割草机路径/开始时间/命中列表、传送剩余次数与出口和野怪锁敌均保存于格子快照。重开重新初始化，恢复不重发一次性收益。
- 门通过移动前后脚点检测穿越；停留不重复触发。两方共用窗口和冷却。门和传送门不进入攻击候选，可通过原有占领流程易手。
- 克隆走原有产兵入口和人口上限，继承基础属性、门效果及最大生命，满血出生；当前状态使用独立实例和原剩余时间复制，常驻被动不丢失，也不把加成重复固化。
- 割草机从资源格朝开启它的相邻格的反方向直线推进，无血量；按移动进度结算伤害和占领，经过中立空地时归属触发方，非中立格保持原归属。遇城墙、建筑继续前进，仅虚空与地图边界结束路线；对敌方结构按触发时全队总攻击力结算一次伤害，优先伤害城墙，无城墙时伤害建筑，沿用既有摧毁与奖励流程，不伤害友方结构。结构命中由路径进度去重，恢复不重复扣血；单单位整条线最多受伤一次。已触发的推车资源格允许小兵按普通占领规则易手，未触发时保留资源；后续建造始终遵守普通锚点规则。每名玩家每局最多触发一次割草机，使用次数依据快照中的 `mowerOwner` 与 `startedAt` 判断，资源格易手或恢复存档不刷新次数，新局重置。已使用的玩家不再触发其他割草机点，不阻止尚未使用的其他玩家从已开启邻格触发。
- 周期产兵、首波和号角波共用兵营批次入口，不更改原兵营时钟。传送仅双人局投放；每批选择一次出生格、扣一次次数，耗尽时进入冷却，时间到全量恢复。范围内没有敌兵时，沿敌方主城方向取最大范围内的有效落点，不因主城较近而提前停止。
- 传送单位的 `portalFlight` 保存入口格、真实产兵兵营和批次起始时间；按同一表现时间轴抛物线飞向出口，飞行完成才离开出生状态。出生规则不额外提供无敌；恢复快照继续原时间轴，不重扣次数。产兵抖动仍指向真实兵营。
- 野怪复用格子生命与建筑目标命中链；睡眠不入索敌、不能受伤，唤醒后原地锁敌，脱战保留生命。死亡只发一次现有单位击杀金币奖励。
- 强化门、衍生地块、传送门使用新增透明图标，号角复用现有黄金号角素材，野怪复用已有单位待机骨骼和格子血条。对局不显示趣味资源的名称、状态或冷却文字，图标缩小至原来的 85%。四种门分别使用 `gate_add`（绿、多兵）、`gate_multiply`（金、分裂分支）、`gate_shrink`（蓝、内收箭头）、`gate_enlarge`（红、外扩箭头）；随机门按快照中的当前 effect 切换图标。
- 强化门冷却时图标变暗，现有圆环按配置总时长与快照 readyAt 显示恢复进度；窗口生效时显示完整放大亮环，可用时收起。冷却配置在资源抽取接入时注入视图，不在帧循环查表；换格和选点时恢复原圆环尺寸。

割草机复用 `extension.png` 图标槽位，按开始时间逐帧沿路径移动，结算与动画共用模型时钟；传送入口和出生点由 `ZCEffectPool` 复用已加载的 `portal` 图形独立播放开合，入口圆环持续显示次数/冷却，不被开合动画覆盖。开合节点按格面尺寸定大小，经现有节点池回收，换局与销毁统一释放；飞行时长集中在 `ZC_PORTAL_FLIGHT_SECONDS`，抛物线高度按格面高度推导。图标位于 `assets/bundles/battle/image/map-resource/`，沿用该目录的自动图集。`ZCGameLoader` 使用本局 AssetService/scope 从 battle 包加载，经过 `ZCGame`、`ZCGameRenderWorld` 注入地块视图；趣味资源缺图时也不回退文字。新生成的三张图标按 256×256 导入。

地图编辑器从同一个 battle 目录提供图标；组合点预览最高正权重项，强化门由 param.gateIds 首个引用行的 effectType 选择预览变体，不参与或改变游戏随机抽取。左栏提供带名称的组合 ID 候选和当前画笔图标，画布保留组合编号与悬停名称；野怪按 param.resId 引用卡牌 buildIcon，不再统一使用大嘴花示意图。修改候选卡牌后重启编辑器服务以更新预览资源清单。

野怪类型由各自单位骨骼区分；沉睡使用蓝色月牙小标，模型偏暗、待机速度为 0.35；唤醒使用红色利爪小标，恢复白色和正常速度。状态标记目标尺寸为 32 像素，位于模型右上方；不显示文字，击败后模型与标记一起隐藏。状态变化进入视图内容签名，复用模型时全量重置颜色与速度，不重建节点。

单ID强化门整局固定，多ID强化门每次从其余引用效果中选下一种。野怪平均等级、强度倍率、归属结算及复活仍不引入新算法，沿用现有配置卡属性和击杀奖励口径。
