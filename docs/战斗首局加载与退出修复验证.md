## 退出报错复现与修复

真实Cocos引擎最小复现：领地无作用域加载 `image/buildings/img_land_01/spriteFrame`，战斗作用域加载 `image/buildings` 后持有同一帧。退出战斗后refs从1变0，图片失效且uv为空，领地Sprite仍然active。得到与截图相同的 `Cannot read properties of null (reading '0')`，记录 `.codex-artifacts/battle-exit-repro.json`。

加入领地独立引用后，战斗退出时refs为1、帧及uv均有效；领地节点销毁后refs为0正常回收；错误为0。记录 `.codex-artifacts/battle-exit-fixed.json`。

真实引擎连续两轮主界面→四方战斗→主界面，返回后强制清空战斗缓存、标记所有Sprite重绘，两轮失效主界面帧均为空，页面及控制台错误均为0。记录 `.codex-artifacts/battle-oct27-flow.json`。该探针使用软件渲染，在资源准备期间暂停绘制来隔离GPU竞争，不能用于承诺实际账号返回主界面的总时长。
