# 战斗首帧优先与特效补载（2026-10-27）

用户接受“初期短暂使用通用表现”。正式开战已拆为首帧资源与后补表现两阶段，适用于持有战斗作用域并收到服务端阵容的入口，包括领地、世界及匹配。无服务端回包的离线入口沿用原全量准备方式。

## 行为与边界

首帧等待地图、配置、全部本局单位模型（含召唤、波次和中立奖励单位）、HUD、棋盘、建筑及交互资源；不等待专属弹道、出生/阵亡/职业受击/拆建筑特效、地图装饰。地块激活与神器领取的序列帧暂留首帧阶段。没有修改后端阵容、战斗规则或随机源。

真正 after-draw 后才启动逐项补载，每次只派发一个根资源，项间让出16ms。尚未就绪的弹道/近战/范围表现使用通用几何，受击使用0.15s通用闪光；出生/阵亡等辅助表现未就绪时跳过。每项成功显式通知渲染世界，后续事件用最新Prefab，已经播放的通用效果自然结束。失败保留通用表现并告警。退出时解绑尚未触发的after-draw，作用域取消后不再派发或发布迟到结果。

前台首帧优先级100、后补10、静默预热-10；不打断已经展开的引擎请求。排队任务按优先级及同级FIFO派发，同路径命中共用任务并提优。Cocos适配使用公开loadAny请求透传priority；根资源并发仍为4。

8个核心外壳逐个预热成功后以会话租约保留，仍包含在64条缓存预算内；不是额外增加8条，也不代表刚打开主界面就已全部准备好。退出登录统一释放。地图装饰只由本局持有。原有领地独立持有共享SpriteFrame及绘制后释放机制保留。

日志区分“首帧资源准备完成”“首帧已绘制，开始后补特效”“完整特效准备（首帧后）”。各资源组等待包含排队与依赖，不可相加作为下载总耗时。
