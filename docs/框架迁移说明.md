# 客户端框架迁移说明

## 当前依赖方向

```text
app/bootstrap
    ├── core ports
    ├── platform adapters
    ├── framework/procedure
    └── app procedures/features

app feature/application ──> core ports + pure domain systems
platform adapters        ──> core ports + legacy implementation
framework/procedure      ──> core runtime/asset
```

约束：

1. `core/**` 禁止依赖 `cc`、`framework`、`app`。
2. `framework/**` 禁止反向引用具体业务流程。
3. 业务页面按 `GameRoute` 导航，不 import 其他 `Procedure*`。
4. 正式流程中的资源加载必须经过 `AssetService`，配置必须经过 `ConfigService`，网络必须经过 `NetworkTransport`。
5. 每次导航拥有独立 `ResourceScope`；成功进入后交给流程，失败、被覆盖或退出时释放。

## 已迁移内容

- `ProcedureBootstrap` 已迁到 `app/bootstrap`，保留原 `.meta` UUID，`Root.scene` 无需重绑。
- `GameContext` 统一提供 `AssetService`、`ConfigService` 与 `NetworkTransport`。
- `LoginGateway` 只依赖网络端口；`fetch`、超时和本地 CORS 代理集中在 `FetchNetworkTransport`。
- 登录流程在组合根创建网关并注入 `LoginPage`，页面不再自行选择网络实现。
- 已删除未再使用的 `framework/asset` 旧门面；`RefUtil` 直接通过 Cocos `remoteRef` bundle 读取配置资源。
- Login、Main、Matching、Battle 四个流程已按 `GameRoute` 注册和导航。
- Cocos 资源加载集中到 `CocosAssetService`，支持 resources/custom bundle 与作用域引用释放。
- 原 `RefUtil` 已包装为 `RefConfigService`，并发初始化只执行一次。
- `ZCGameLoader` 独立负责 PVP 配置、地图选择和对局首屏资源准备。
- `ZCGame` 正式启动路径只消费准备结果，规则与显示资源加载不再由 Component 编排。
- 匹配图标和提示配置由流程预加载并注入页面；页面不再读取全局配置。
- 流程切换支持覆盖旧预加载，旧导航的资源作用域立即释放。
- `ZCGameModel` 已开始按职责委托给四个纯 TypeScript 模块：
  - `ZCArtifactSystem`：快照归一化、充能、储存、激活与冷却；
  - `ZCEconomySystem`：建筑工作状态、周期、冷却进度与矿产公式；
  - `ZCTargetingSystem`：全图目标排序、射程判定与通用 BFS；
  - `ZCCombatSystem`：单位状态切换、伤害公式、有效伤害和攻击飞行时间。

## 流程资源生命周期

```text
navigate(route)
  → 创建 ProcedurePreloadContext + ResourceScope
  → onPreload(params, context)
  → 成功：scope 移交给目标 Procedure → onEnter
  → 失败/被新导航覆盖：context.cancelled = true → dispose scope
  → onLeave：先销毁节点，再 dispose scope
```

所有异步 `onPreload` 在写入流程字段前都要检查 `context.cancelled`，并在
`onPreloadCancelled` 清理已经写入的临时引用。

## 后续迁移顺序

1. 将 Combat 的命中编排、死亡/奖励事件继续迁入系统输入输出，减少模型对表现事件的直接写入。
2. 将 Economy 的时间推进改为事件列表（产金、出兵、建造完成），由模型统一落状态。
3. 将 Targeting 的目标解析与路径缓存迁入独立会话对象，并补齐前后方过滤规则。
4. 将卡牌、指南等剩余的 `resources.load` 迁到按功能创建的资源加载器。
5. 移除 `ZCGame` 仅用于编辑器直挂的旧资源加载兼容分支。
6. 清理确认无引用的 Cocos 2.x `cc.*` 遗留模块。
