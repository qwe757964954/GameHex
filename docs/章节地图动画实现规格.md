# 章节地图 · 动画反馈实现规格（WorkBuddy 可直接落地版）

> 来源：根据 `章节地图-效果2-1.mp4`（15s）、`章节地图效果参考-1-1.mp4`（12.8s）逐帧拆解（30fps）。
> 所有时间轴、缩放、缓动、粒子数量均按视频实测给出，可直接换算为 Tween/粒子参数。
> 引擎无关：Unity（DOTween）、Cocos（tween）、UGUI 均可直接套用；缓动统一给 Cubic-Bezier 参考值。
> 配套关键帧参考图见同目录 `动画帧参考/` 文件夹（帧图左上角为精确时间戳）。

## 0. 通用约定

### 0.1 缓动曲线（全文档复用）

| 命名 | 曲线 | 用途 |
|---|---|---|
| SpringPop | scale 0→1.15→1.0，0.25s，可拆为 `Back.easeOut(amplitude=1.15)` | 地块、宝箱、数字的弹出 |
| PressBounce | scale 1→0.94→1.02→1，0.18s | 地块点击按压回弹 |
| EaseOutCubic | cubic-bezier(0.215, 0.61, 0.355, 1) | 光环扩散、镜头推拉 |
| EaseInQuad | cubic-bezier(0.55, 0.085, 0.68, 0.53) | 光柱劈下 |
| FlyArc | 高度固定的抛物线（见 0.3） | 资源图标飞向顶部栏 |
| Float | 上下 6~10px 正弦呼吸，0.6s/周期 | 提示条、待开宝箱蓄力 |

### 0.2 层级（Sorting Order，从小到大）

地块本体(10) → 地块按压光圈(15) → 地块建筑(20) → 宝箱(25) → 资源飞行图标(40) → 光柱/光束(35，半透明) → 粒子(45) → 爆点白光(50) → 全屏暗角/遮罩(60) → 顶部资源栏(100) → 飘字数字(110)

### 0.3 资源飞行组件（FlyReward，三处复用：点击产出、弱/中/强宝箱）

- **路径**：以起点（地块中心）和终点（顶部对应资源图标中心）构造二次贝塞尔，控制点 P1 = 起点 + 向上偏移（屏幕高度的 18%~25%）+ 向终点方向水平偏移 30%。
- **飞行时间**：0.55~0.7s，`EaseOutCubic`。
- **图标表现**：飞行中绕 Y 轴（屏幕法线）每 0.25s 翻一周（金币正反面）；宝石类改为缓慢自转 + 周期性闪烁高光；可加 1 个半透明拖尾残影（延迟 0.05s、alpha 0.35）。
- **多枚错峰**：每枚间隔 0.05~0.08s，起点加 ±15px 随机抖动，控制点高度加 ±10% 随机。
- **到达**：图标在终点处 scale 1→0.3 被"吸入"（0.12s），同时播放栏位闪光 + 数字滚动。

### 0.4 顶部资源栏接收组件（BarCatch）

- **预亮**（资源起飞时即触发，早于到达）：目标图标外圈加 Additive 光晕，alpha 0→0.8，0.2s。
- **吃入**：图标 scale 1→1.18→1 弹跳 0.2s + 白色闪光遮罩闪一次（0.15s）。
- **数字**：数值从旧值滚动到新值（0.3~0.5s，按差额大小），数字瞬间变黄、scale 1.25→1 回弹；数字滚动用"快-慢"减速，末位用整数跳变。
- 多个资源连续到达时，闪光可重复刷新、数字滚动接续不累加延迟。

## 1. 点击地块获得资源（单次约 0.8~1.0s，可连续触发）

参考：`04_点击地块资源飞出_参考A.jpg`、`05_点击地块资源飞出_参考B.jpg`（v2 4.4~6.0s 为一次完整点击）。

### 时间轴（t=0 为手指按下）

| 时间 | 地块层 | 资源/粒子 | 顶部资源栏 |
|---|---|---|---|
| 0.00~0.05s | PressBounce 按压；被点地块叠加绿色径向光圈（中心亮、边缘透明，0.3s 淡出） | 点击点出现 1 个蓝色小圆环，scale 0.4→1.4、alpha 1→0，0.3s | — |
| 0.05~0.15s | 地块恢复 | — | **对应资源图标预亮**（Additive 光晕渐强） |
| 0.12~0.25s | 地块中心 SpringPop 弹出 2~4 个资源图标（scale 0→1） | 金币带一次小蹦跳（向上 10px 再落） | — |
| 0.25~0.70s | — | 资源图标走 FlyArc 抛物线飞向顶部栏（见 0.3），金币自转、带拖尾 | 光晕保持 |
| 0.60~0.80s | — | 图标到达被吸入 | BarCatch：图标弹跳 + 白光闪 + 数字滚动变黄 |
| 0.80~1.0s | 地块产出数字（如"30"）SpringPop 弹一次后常驻 | — | 数字更新完毕 |

### 连续点击规则

- 每次点击独立播放，互不打断；地块按压光圈与圆环各自完整播完。
- 飞行图标可并发（同屏上限约 12 个，超出按最早者加速 1.5 倍）。
- 顶部栏预亮在飞行中被新请求刷新（重置 0.2s），数字滚动以最后一次差额为准。

### 实现要点（WorkBuddy 快速做法）

1. 地块加一个 `TapPunch` 脚本：按下只做缩放 + 光圈；在 `PointerUp` 时 `SpawnReward()`。
2. 资源图标用对象池（金币/钻石/宝石各一个池），每枚是一个 Tween 序列（弹出 → 贝塞尔飞行 → 吸入）。
3. 顶部栏按资源类型注册落点坐标，飞行组件只认"资源类型"，不认具体地块。
4. 绿光圈、蓝圆环各用一张径向渐变贴图（UGUI Image 或粒子 Billboard），不必做 Shader。

## 2. 新地块生成动画（整组约 1.2~1.5s）+ 解锁变绿

参考：`01_新地块生成_蓝色传送门_参考.jpg`（v1 0.87~2.1s）、`02_新地块生成_金色传送门_参考.jpg`（v2 0.6~2.0s）、`03_地块解锁变绿与提示条_参考.jpg`（v2 2.0~4.1s）。

### 阶段 A：传送门聚能（0 ~ 0.35s）

- 生成点中心出现能量旋涡：1 个持续旋转的螺旋/环形 Sprite（旋转一周 0.5s），颜色按稀有度分 **蓝（普通）/ 金（稀有）**。
- 外圈 2~3 个同心圆环依次扩散：每个圆环 scale 0.3→1.6、alpha 1→0、0.45s，间隔 0.12s 错峰，`EaseOutCubic`。
- 中心亮度做一次 0→1→0.7 的脉动（0.3s）。

### 阶段 B：地块涟漪式弹出（0.2 ~ 0.9s）

1. **中心地块先出**：0.15s 时中心 1 块六边形从旋涡中 SpringPop 浮现（scale 0→1.15→1，0.25s）。
2. **邻居按距离分波**：与中心的六边形距离分 2~3 波（ring 1 / ring 2 / ring 3），每块延迟 = 距离 × 0.06~0.08s，各自独立 SpringPop。
3. 每块弹出瞬间，在该地块位置生成 1 个小气泡/尘粒：灰色小圆点，向上飘 20~30px、scale 0.8→0、alpha 1→0，0.4s；一组共 6~10 个，随机水平偏移。
4. 全部地块初始为**灰色未解锁态**。

### 阶段 C：解锁变绿 + 数字（约 0.9 ~ 1.4s，视解锁时机）

- 中心地块先变绿，绿色高亮以中心为圆心做**径向水波扫过**（一张绿色圆形 Fill/遮罩，scale 0.2→2.5，0.4s，EaseOutCubic），扫到的地块灰色贴图切换为绿色。
- 产出数字"30"在地块角标处 SpringPop 弹入（0.2s）。
- 地块上的建筑（小宝箱/小建筑）同帧 SpringPop，落位后带一次金色呼吸高光（0.6s，循环 2 次后停），引导玩家点击。

### 阶段 D：引导提示条

- 地块上方深色半透明圆角条（白字"已解锁，点击宝箱领取"）：从上方 20px 位置下滑 + alpha 0→1，0.25s，`EaseOutCubic`。
- 落位后做 Float 轻微呼吸（±4px），直到玩家点击该地块时整体淡出（0.15s）。

### 实现要点

- 地块排布本身是六边形网格，直接按"到生成中心的六边形步数"排序播放，无需路径计算。
- 旋涡、圆环、气泡均可做成一个 `TileSpawnVFX` 预制体，颜色字段（蓝/金）由配置传入。
- 变绿水波若用 Shader 成本高，可用"一张随时间放大的绿色圆形渐变 Sprite + 地块贴图按距离切换"近似，视觉一致。

## 3. 宝箱奖励三档（弱 / 中 / 强）

三档共用"宝箱出现→蓄力→开盖→爆光→奖励飞"的骨架，按档位叠加镜头、光柱、粒子规模。参考图：
- 弱：`06_宝箱弱档_地块小宝箱开箱_参考.jpg`、`07_宝箱弱档_收尾_参考.jpg`（v1 4.4~7.5s）
- 中：`08_宝箱中档_光柱与金币喷泉_参考.jpg`、`10_宝箱中档_白光中树弹出_参考.jpg`、`09_宝箱中档_金币雨收尾_参考.jpg`（v2 10.6~13.2s）
- 强：`11_宝箱强档_镜头拉近开箱彩虹光_参考.jpg`、`12_宝箱强档_奖励汇聚与拉远_参考.jpg`（v1 8.4~12.7s）

### 3.1 弱档（地块小宝箱，总时长约 2.5~3s，无镜头变化）

| 时间 | 表现 |
|---|---|
| 0.00~0.25s | 宝箱在地块上 SpringPop 出现（关闭态，金属描边高光闪一次） |
| 0.25~0.35s | 蓄力：宝箱轻微下压（scale Y 0.96）后回位，0.1s |
| 0.35~0.50s | 箱盖绕底铰链向上弹开（旋转 0°→-115°→-105°，0.15s，带回弹）；箱口白光爆闪 0.1s（白块 alpha 0.9→0）；8~12 条金色径向光条从箱口向外（scale 0.5→1.4、alpha 0.9→0，0.4s） |
| 0.50~1.3s | 金币/紫宝石/钻石各 2~4 个从箱口 SpringPop 弹出后走 FlyArc 飞向顶部栏（复用 0.3），宝石自转 + 高光闪烁 |
| 1.3~2.5s | 顶部栏按到达顺序依次 BarCatch（图标闪光 + 数字滚动），每类间隔 0.1~0.15s |
| 2.5~3.0s | 箱内光线淡出；宝箱保持开盖静态留在地块（可点击/可消失，按业务） |

**禁止**：无镜头移动、无全屏遮罩、无粒子雨。

### 3.2 中档（光柱宝箱，总时长约 2.6s，光柱贯穿屏幕 + 全屏金币雨 + 建筑升级）

| 时间 | 表现 |
|---|---|
| 0.00~0.25s | 宝箱在地块上 SpringPop 出现（同弱档） |
| 0.25~0.45s | 蓄力：宝箱上下浮动 2 次（±8px，0.1s/次），金属高光脉冲 |
| 0.45~0.65s | **光柱劈下**：上宽下窄的白色/金色锥形（梯形）体积光束从屏幕顶部落到宝箱，alpha 0→0.9，0.2s，`EaseInQuad`；落点同时炸开一圈水平光环（scale 0.3→1.8，0.35s） |
| 0.65~1.15s | 光柱持续照射 0.5s（光束做明暗呼吸 + 贴图向下流动，强度 ±15%）；宝箱在光中开盖（开盖动画同弱档），箱内金光 |
| 1.15~1.30s | 宝箱位置**白色爆点**（径向白光 scale 0.2→2.0，alpha 1→0，0.15s）；光柱同步 0.15s 快速淡出 |
| 1.25~1.45s | **升级建筑（大树）从白光中 SpringPop 弹出**（scale 0→1.2→1.0，0.3s，树冠多叠一层 0.05s 错峰）；与金币喷泉同时 |
| 1.20~2.5s | **金币喷泉**：30~50 枚金币从爆点以 60°~100° 扇形上喷，初速度向上 600~900px/s（按分辨率折算）、水平随机 ±350px/s，重力约 1400px/s²，金币自转 + 发光；落地后淡出或飞出屏幕 |
| 1.20~2.6s | **彩色星光粒子**：四角星 + 小圆点 40~60 个（青/紫/黄/绿/粉随机），从爆点径向扩散（初速度 200~500px/s 随机、无重力），自转 + 漂浮，生命周期 1.5~2.5s 后 alpha 淡出 |
| 2.0~2.6s | 顶部资源栏数字滚动累加（金币总额一次滚动到位）；粒子渐隐，画面恢复 |

**关键**：镜头全程不动；光柱是唯一的全屏元素；树的弹出必须与白光爆点同帧，形成"光里变出建筑"的错觉。

### 3.3 强档（全屏大宝箱，总时长约 4s，镜头拉近 + 彩虹光束 + 高密度奖励）

| 时间 | 表现 |
|---|---|
| 0.00~0.30s | **镜头 ZoomIn**：地图视角推向宝箱至约 2.2~2.5 倍（0.3s，`EaseOutCubic`），宝箱从地块位置冲到屏幕中央，起始带径向运动模糊/速度线（可退化为 4~6 条半透明速度线） |
| 0.00~0.30s | **全屏压暗**：径向暗角（vignette）+ 半透明深色遮罩 alpha 0→0.55，0.25s，把视觉聚焦到中央 |
| 0.30~0.50s | 宝箱 SpringPop 落定（冲过冲到 1.1→1.0，落地微颤 1 次），关闭态铜色大箱体；周围气流速度线绕箱旋转 |
| 0.50~0.70s | 蓄力停顿 0.2s（箱体上下浮 1 次 + 锁扣处高光闪） |
| 0.70~0.95s | 箱盖两段式弹开（0°→-120°→-108°，0.2s）；箱内白光爆闪；金色放射光条 14~18 条（比弱档更粗、更长） |
| 0.95~1.30s | **彩虹光束**：紫→蓝→青→绿→黄→粉的径向渐变锥形光从箱口喷出，整体缓慢旋转（约 30°/s）；外圈 2~3 波彩虹光环扩散（scale 0.4→2.2，每波 0.5s，间隔 0.2s） |
| 1.20~2.60s | **高密度奖励喷泉**：金币 15~25 枚 + 大颗紫水晶 4~6 颗 + 蓝钻石 4~6 颗连续喷涌（按 0.08s 间隔分 3~4 批），先上抛再重力回落；宝石带发光拖尾；随机 20~30 个白色四角星 twinkle（0.2s 明 / 0.3s 灭循环） |
| 2.60~3.50s | 大颗宝石沿 FlyArc 飞向屏幕边缘资源栏（飞行 0.7~0.9s）；金币回落箱口做堆叠跳动（落地 bounce 衰减 0.4）；宝箱随每次喷发上下颠簸 ±6px |
| 3.50~4.00s | **镜头 ZoomOut**：0.4s 回到正常视角（`EaseInQuad`），宝箱同步缩小回地块尺寸；暗角 0.25s 淡出，彩虹光 0.3s 淡出，收尾播放 BarCatch 数字结算 |

## 4. 落地清单（WorkBuddy 可直接建的预制体/组件）

1. **Tween 库**：确认 SpringPop（Back easeOut, overshoot 1.15）、PressBounce、Float 三条曲线配置。
2. `TileTapPunch`：地块按压脚本（缩放 + 绿光圈 + 蓝圆环 + 调起资源池）。
3. `FlyReward`：贝塞尔抛物线飞行组件（起点、资源类型、终点由类型查表），对象池 3 种。
4. `TopBarCatch`：栏位预亮 / 吸入 / 数字滚动（挂在顶部栏每个资源位上）。
5. `TileSpawnVFX`：旋涡（蓝/金换色）+ 同心圆环 + 地块分波 SpringPop + 气泡；含绿色水波扫过 + 数字弹入 + 引导提示条。
6. `Chest`：状态机（出现→蓄力→开盖→爆光→喷发→收尾），档位参数表化（数量、光条数、是否光柱/彩虹/镜头）。
7. `LightBeam`：上宽下窄锥形光束（白/金），含落下、呼吸流动、淡出三段。
8. `RainbowBeam`：彩虹径向渐变锥光 + 旋转 + 光环波次。
9. `CoinFountain` / `StarBurst`：两个粒子发射器（重力金币雨、无重力星光扩散），参数暴露数量/初速度/重力/生命周期。
10. `CameraPunch`：ZoomIn/Out + 速度线 + 全屏径向暗角（强档专用，弱/中档不调用）。

### 音效配合建议（供参考，非视频内信息）

- 地块点击：短促"叮"；资源入栏：合并的清脆"叮叮"。
- 地块生成：旋涡"嗡"上升音 + 每波弹出"啵"。
- 宝箱：开盖"嘭"（弱→中→强音调/时长递增）；中档光柱加"唰"下落音；强档加彩虹阶段的上扬和弦。

## 5. 验收口径（对照视频）

- 点击地块：0.1s 内看到按压反馈，资源起飞前顶部栏先亮；0.8s 内完成飞入与数字跳动。
- 新地块：传送门光环先于实体；地块由近及远分波弹出，错峰肉眼可辨；绿色由中心扫开而非整块瞬变。
