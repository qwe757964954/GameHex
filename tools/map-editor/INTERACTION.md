# 三套地图编辑器 · 交互体验方案

> 三套 = 对局地图（`index.html`）· 章节领地（`territory.html`）· 大地图（`bigmap.html`）
> 使用者是同一批策划，**同一套肌肉记忆必须通用**；但三个领域（格子协议、整章布局、100×100 世界）不同，
> 不能为了"统一"把好用的差异也抹平。
> 本文记录 2026-10-20 这轮收敛的结果、**仍该修的**和**刻意不动的**，以及新编辑器接入时的验收清单。

## 3. 两处已修、三处别动

### 3.1 ✅ 已修：对局地图的画布缩放已提到顶部（2026-10-20）

原来画布缩放没有可见入口，而「高级设置 → 镜头倍率」里的 `zoomMin/zoomMax` 是**写进地图 JSON 的局内镜头区间**（数据），
两件事名字撞在一起很容易改错。现在：

- 顶部加 **40%~600% 滑块**（对局地图原有 `zoom` 范围本来就是 0.4~6）；
- 「高级设置 → 镜头倍率」**原样保留**，它确实是低频数据，只是不再承担"画布缩放"的角色；
- `zoomAt` 抽成 `zoomTo(target, x, y)`：滚轮传光标、滑块传画布中心。

### 3.2 ✅ 已修：对局地图补了 `1`~`5` 与 `Esc`

对局地图的"工具"是 5 个分类 tab，所以数字键映射到分类（另两套是映射到工具按钮，语义一致：都切工具组）。
`Esc` = 先取消装饰选中，没有选中就回「地图地形」。

### 3.3 ⚠️ 别动：右键语义三套不同

| 编辑器 | 右键 | 为什么 |
| --- | --- | --- |
| 章节领地 | 擦除刷（拖着擦一片） | 领地站点密集，连续擦是最高频动作 |
| 大地图 | 单击擦除 / 拖动平移 | 100×100 靠滚动条太难受，而它没有"拖刷"需求 |
| 对局地图 | 擦除当前笔刷 | 与笔刷模型一致 |

**这条差异是有意的**，已在各自 README 写明。以后谁提"统一右键"，先看这条。

### 3.4 ⚠️ 别动：缩放范围不同

`领地 50~400%` / `大地图 30~220%`。领地是 20×20 以内的精细排版，需要放大看细节；
大地图要看整体，不需要 4 倍。数字不同是对的，**统一的是交互（滑块 + 百分比 + 滚轮锚点），不是取值范围**。

### 3.5 ⚠️ 别动：对局地图的保存模型

它是「改一格即时标记 + 显式保存 / 覆盖预设」，另两套是「改完统一保存」。
这是由产出物决定的（对局地图直接进 `assets/resources/config/maps/` 参与随机池），不强行统一。

## 4. 提炼出的六条设计原则

1. **入口跟着频率走**：高频操作放顶部常驻（预设、缩放、保存），低频配置留在折叠 tab。
   判据：「换个图看」这种动作不该需要切两层。
2. **同一动作三种输入必须互相同步**：滑块、滚轮、`适应窗口` 改的是同一份 `zoom`，
   `applyView()` 里统一回写控件值 —— 否则控件会跟画面脱节。
3. **缩放锚点要按输入源分开**：滚轮以光标为锚（看哪里缩哪里），滑块以视口中心为锚（拖的时候不跑偏）。
   混用一个锚点是这类编辑器最常见的手感问题。
4. **打开文件不等于编辑**：载入预设 / 导入 JSON 一律清空撤销栈，且不标记未保存。
5. **破坏性操作先确认，但只在真有损失时**：有未保存改动才 `confirm`；干净状态直接切。
6. **空状态不占位**：没有预设时下拉整个 `hidden`，不要留一个只能选「无」的控件。

### 共享层的边界（2026-10-20）

`formats/ui-kit.js` 只收了**行为完全一致**的三样：`setDirtyBadge` / `syncZoomSlider` / `bindZoomSlider`
（外加 `zoomPercentLabel` 统一百分比格式）。

**为什么只覆盖两套**：`territory.html` / `bigmap.html` 用 `<script type="module">`，能 import；
**`index.html` 是 IIFE + 普通 `<script src>`**，import 不了 ESM。把它改成 module 会动它的顶层作用域，
为一个 15 行的工具不值得。对局地图那边靠**约定**保持一致（同样文案、同样百分比口径）。

**为什么不再抽更多**：预设下拉的标签（`id · 名称 · N 站点` vs `id（W×H，N 城）`）、
确认弹窗的文案、右侧面板结构，三套差异都很大 —— 强行统一会把各自好用的部分磨平。

⚠️ **两套的 `zoom` 语义不同**：领地存**倍数**（0.5~4），大地图直接存**百分数**（30~220）。
所以 ui-kit 只认百分比，换算留在调用方。这是本节唯一容易踩的地方。

## 6. 新编辑器接入验收清单

以后再加一套编辑器（或大改交互），至少过一遍：

- [ ] 顶部有：预设下拉、画布缩放滑块 + 百分比、保存、撤销/重做
- [ ] 快捷键：`Ctrl+S` / `Ctrl+Z` / `Ctrl+Y`（或 `Ctrl+Shift+Z`）/ `Esc` / `Delete` / `1`~`9`
- [ ] 键盘处理排除 `INPUT` / `SELECT` / `TEXTAREA`（否则输入框里按数字会切工具）
- [ ] 缩放：滑块→中心、滚轮→光标；`适应窗口` 回 100% 且滑块同步
- [ ] 载入预设清空撤销栈、不标脏；有脏改动时先 `confirm`
- [ ] 六边几何从 `formats/hex-grid.js` 取，**不要自己写邻居**
- [ ] 校验规则只有一份权威实现，浏览器侧那份要有对拍测试
- [ ] 空状态不占位
- [ ] 规则说明：高频分组折叠、低频 tab 直接铺开
- [ ] 无头浏览器探针覆盖：渲染数量、点击选中、一次编辑 + 撤销、页面零 console 错误
